# Security Policy

XRBitcoinCash welcomes responsible reports concerning the official website, XRPL/Xaman xApps, public APIs and proxies, auditing and risk tools, bridge-monitoring interfaces, tokenization workflows, support systems, and published metadata under `xrbitcoincash.com`.

## Reporting a vulnerability

Use one of these official routes:

- Email: security@xrbitcoincash.com
- Support form: https://xrbitcoincash.com/support.html#support-form
- Disclosure record: https://xrbitcoincash.com/.well-known/security.txt
- Encryption key: https://xrbitcoincash.com/pgp-key.txt

Include the affected page or component, reproducible steps, expected and observed behavior, impact, and a safe proof of concept when appropriate.

Never include an XRPL family seed, private key, recovery phrase, Xaman passcode, API secret, password, or other secret credential. Use public transaction hashes or public XRPL addresses only when they are necessary to reproduce the issue.

## Coordinated disclosure

Please allow a reasonable opportunity to investigate and correct a confirmed vulnerability before publishing exploit details. Reports involving a third-party platform should also be sent to that provider when the affected behavior is outside XRBitcoinCash-controlled code.

This project does not promise a bounty or payment unless a separate written bounty program explicitly says otherwise.
