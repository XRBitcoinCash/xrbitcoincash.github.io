OBS setup

  1. Open Settings → Audio and disable general Desktop Audio to prevent duplicated audio.
  2. In the Sources panel, click + and add Application Audio Capture.
  3. Select the Arma Reforger application and name the source Arma Reforger Audio.
  4. Add the microphone separately using Audio Input Capture.
  5. Open Settings → Output and change Output Mode to Advanced.
  6. Under Recording, use MKV and enable Tracks 1, 2, and 3.
  7. Open Advanced Audio Properties from the Audio Mixer.

Clipchamp limitation

Clipchamp will normally treat the OBS recording as one video with one accessible audio stream. It generally does not place the embedded OBS tracks on separate timeline lanes.

Using Detach audio only separates the currently selected audio from the video. It does not divide the Arma Reforger audio and microphone audio into separate tracks.

Best practice: Keep Track 1 as the complete game-and-microphone mix so Clipchamp can play the recording normally. Tracks 2 and 3 can be used later in an editor that supports embedded multitrack audio.

Editing the tracks separately

To use the separate tracks in Clipchamp, first extract Track 2 and Track 3 into individual WAV, MP3, or AAC files, then import and align them with the video.

A multitrack editor such as DaVinci Resolve is generally easier because it can directly recognize the separate OBS audio tracks.

Important Arma Reforger limitation

Arma Reforger voice chat and game sounds normally come from the same application audio source. Track 2 can separate the game from your microphone, but it cannot completely isolate player voices from gunshots, engines, and environmental sounds.
